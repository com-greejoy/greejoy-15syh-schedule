# 证书底图说明

本目录存放群众组电子证书的底图静态资源。

| 文件            | 用途     | 尺寸（来源像素分析）  |
| --------------- | -------- | --------------------- |
| `pub-join.jpg`  | 参赛证书 | 825 × 1166（A4 纵向） |
| `pub-award.jpg` | 获奖证书 | 824 × 1167（A4 纵向） |

## 底图与字段配置的关系

两张底图**已包含完整内容**：标题（"参赛证书 / 获奖证书"）、副标题（COMPETITION / AWARD CERTIFICATE）、叙事文字、label（"竞赛项目："等）、下划横线。前端 Canvas **仅在横线正上方填写动态字段值**，不重绘任何静态元素。

字段坐标定义在 `src/views/game/cert/certConfig.js`，由像素分析脚本得出横线 y%。

## 替换底图时的注意事项

1. **保持同样的横线 y%** —— 否则需要重新调 `certConfig.js`
2. **保持比例与文件名**
3. **保持横线宽度** —— 否则字段值可能溢出
